The diagrams in `img/` are generated by
[`img/diagrams.py`](img/diagrams.py) (`python3 docs/img/diagrams.py`); edit
the script, not the SVG files.

Source-of-truth files (the docs describe them, and the code wins if they
disagree. Please fix the doc):

* `hw/rtl/accel_pkg.sv`: encodings, register offsets, error codes
* `sw/common/accel_isa.h`: assembler syntax
* `sw/common/bf16.h`: numerics
* `sw/common/memory_map.h`: addresses
* `hw/sram/sram_gen.py`: SRAM macro sizes and the generated wrapper `accel_sram_1rw`
* `competition.json`: clock period, area target, synthesis and platform settings
